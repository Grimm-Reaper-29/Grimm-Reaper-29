## What I build

| Project | The problem | What it does | Stack |
|---|---|---|---|
| **Escalation Tracker** | Escalations scattered across calls, WhatsApp and tickets, with no single owner | One tracker for every escalation, with ownership, SLA clocks and trend analytics | Lovable · Supabase · SQL |
| **NPS Recovery Dashboard** | Detractor feedback collected, but no follow-through | Buckets root causes, routes each case to an owner, tracks recovery to closure | Lovable · Supabase |
| **AI WhatsApp Support Bot** | Repetitive customer questions eating agent time | Answers from a knowledge base on WhatsApp and creates helpdesk tickets when a human is needed | WATI · Claude API · Freshdesk |
| **Cross-Functional SLA Analysis** | Leadership could see SLA breaches but not which team caused the delay | Reconstructs ticket hand-off timelines from helpdesk conversation threads to show where time is lost between teams | Python · Freshdesk API |
| **EV Charge Log** | Tracking real running costs of an electric car | Personal expense and efficiency tracker | Lovable · Supabase |

*Public demo versions with sample data are in progress. Company tools are shown only in sanitised form.*

## How I work

- **Start from the metric that matters**: SLA, resolution time, NPS. Build backwards from it.
- **Build fast with AI, verify against the source**: every number is checked against raw data before it reaches a leadership review.
- **Security by default**: row-level security, no secrets in code, no customer data in public repos.
